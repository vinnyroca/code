# Drawing

## Description 

Use the some or all of the follow functions to create your own drawing in p5.js.

1. `circle()`
2. `square()`
3. `rectMode()`
4. `line()`

Your drawing may be representational or abstract, refer to the lecture notes for a refresher on the above function
