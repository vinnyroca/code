# Visual Music

## Description

Using [Amplitude() ](https://p5js.org/reference/p5.sound/p5.Amplitude/) and optionally [.setInput()](https://p5js.org/reference/p5.Amplitude/setInput/) to create a p5.js sketch that dynamically responds to the volume level of a track or series of tracks.
