### Part Two

Using the looping works of Vera Molnar and Ryoji Ikeda as inspiration, create a sketch that creates an art work using for loops.

You have two possible options for this exercise:

1. Create a “machine” that can be used to generate looping art works. Fine tune your program, and select a number of drawings that your program produces.
2. Create an animated looping artwork.
